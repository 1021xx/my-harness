# 실제 작업 흐름

## 작업 순서

1. 작업자가 현재 프로젝트의 `UiStandardRenewal.jsp`에서 대상 컴포넌트의 표준 예시를 확인한다.
2. 작업자가 실제 업무 화면의 include 순서와 변경 영향 범위를 조사한다.
3. 작업자가 공통 클래스의 실제 사용처를 `WebContent/webapps/gaia`에서 확인한다.
4. 작업자가 사용자 변경과 프로젝트 고유 구조를 보존하며 필요한 부분만 수정한다.
5. 작업자가 JavaScript를 수정했다면 `node --check`로 문법을 검사한다.
6. 작업자가 브라우저 캐시를 제거하고 화면의 상태·동작·회귀를 확인한다.
7. 작업자가 정적 검사만 수행했다면 실제 동작이 미확인되었다고 기록한다.
