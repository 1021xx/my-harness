# R2 목적

## 목적 한 문장

기존 프로젝트 ERP 업무 화면을 리뉴얼·유지보수하는 개발자가 대상 화면과 UI 변경 요청을 입력하면, 하네스가 기존 클래스를 우선 사용하여 신규 클래스 생성 수를 0개로 유지하고, 업무 규칙과 데이터 모델을 재설계하지 않으면서 적용 가능한 필수 검사항목을 모두 `PASS` 또는 `해당 없음`으로 완료한다.

## 구성 요소

| 항목 | 기준 |
|---|---|
| 매번 달라지는 것 | 대상 ERP 화면, 관련 파일, UI 변경 요청 |
| 사용자 | 기존 프로젝트 ERP 업무 화면을 리뉴얼·유지보수하는 개발자 |
| 핵심 방지 조건 | 새로 생성한 클래스 0개 |
| 완료 기준 | 적용 가능한 필수 항목이 모두 `PASS` 또는 `해당 없음`; `FAIL` 및 사유 없는 `미확인` 0개 |
| 제외 범위 | ERP 업무 규칙·데이터 모델 재설계 |
