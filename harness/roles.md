# R6 역할

## 역할과 권한

| 역할 | 담당 단계 | 편집 가능 폴더 | 제한 |
|---|---|---|---|
| 조사 에이전트 | 1~3단계 | `runs/<작업ID>/` | 대상 프로젝트 수정 금지 |
| 작업 에이전트 | 승인 후 4단계 | 실행별 `edit_root` 1개 | `edit_root` 밖 수정 금지 |
| 읽기 전용 판정자 | 5단계, G1~G4 | 없음 | 검사 전후 변경 파일 증가량 0개 |

## 편집 루트 규칙

- `edit_root` 최초 기본값은 `D:\project\erp-web\WebContent\`이다.
- 실행마다 절대경로 1개만 허용한다.
- 모든 수정 파일은 정규화된 `edit_root` 내부에 있어야 한다.
- H1 승인 전에는 `edit_root`를 변경할 수 있다.
- H1 승인 후 `edit_root`가 바뀌면 기존 승인을 무효화하고 H1으로 복귀한다.
- 경로가 없거나 접근할 수 없으면 작업을 시작하지 않는다.
- `edit_root`는 실행별 `01-scope.md`와 `status.json`에 기록한다.

## 자연어 트리거

“이 ERP 화면을 기존 공통 컴포넌트 기준으로 리뉴얼해줘”라는 요청과 대상 화면 또는 파일 1개 이상이 함께 들어오면 시작한다.

단순 설명·분석·검토 요청은 실행 트리거로 보지 않는다.
